# Diapositiva 20 — Concepto Normativo · Categoría «abierta»

**3. Conflictó con una aeronave tripulada:**
- El piloto a distancia debe **reducir la altura de vuelo**.
- Debe realizar **maniobras evasivas** en caso de posible colisión con la aeronave tripulada.
- Debe **aterrizar lo antes posible**.

En todo caso, el piloto a distancia **siempre debe interrumpir el vuelo** con UAS cuando su continuación pueda suponer un **riesgo para la aeronave tripulada**.
