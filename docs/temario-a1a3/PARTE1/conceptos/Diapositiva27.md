# Diapositiva 27 — Concepto Normativo · Categoría «abierta» — Subcategoría A1

## UAS con etiqueta de clase C0 — requisitos

- Altura máxima de vuelo **limitada a 120 m**.
- Velocidad máxima **< 19 m/s**.
- **MTOM < 250 g**.
- Controlable y manejable de forma segura.
- Diseñado para **no dañar a personas**.
- **Eléctrico**.
- Comercializado con las **instrucciones del fabricante**.
