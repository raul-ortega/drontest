# Diapositiva 67 — Conocimiento general del vuelo con UAS: Captura de información personal por el UAS

*(Lección 2 «Conocimiento general del vuelo con UAS» — pageid 803)*

## Contenido

- Cuando vuelas con un UAS que cuente con algún dispositivo capaz de captar información personal de un individuo, se debe tener la precaución de no vulnerar la privacidad de otras personas.

- Las principales capacidades que puede tener un UAS relacionadas con la captura de información personal son: **cámaras**, **micrófonos**.

- El grado de impacto del uso de un UAS en la privacidad de las personas no solo depende de las capacidades de captura de datos del UAS, sino también de:
  - El propósito del piloto a distancia que opera el UAS.
  - La extensión y tipo de información personal que son capturadas.
  - Cómo se usa/procesa esta información personal.
  - Quién está volando el UAS.
  - El contexto y ubicación del UAS.
