# Diapositiva 22 — Conocimiento general del vuelo con UAS: Controles de vuelo (multirrotor)

*(Lección 2 «Conocimiento general del vuelo con UAS» — pageid 111)*

## Contenido

- Para lograr cualquier movimiento, lo que hace la controladora es **variar la velocidad de algún motor** para lograr una **fuerza resultante**, que permita a la aeronave realizar el movimiento requerido. Para explicar los movimientos de un giroavión, se toma como referencia una configuración en X de un cuadricóptero.
- **Alabeo (Roll)**: si se aumenta la velocidad de los motores del plano izquierdo, el giroavión se inclina hacia el lado derecho (fuerza de desplazamiento a la derecha).
- **Resultante de fuerzas / Planta**: resultante de fuerzas para alzado.
