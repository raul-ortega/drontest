# Diapositiva 3 — Procedimientos operacionales previos al vuelo: Comprobación previa (MEUH)

*(Lección 3 - Procedimientos operacionales — pageid 53)*

## Contenido

- Antes de iniciar un vuelo con UAS se deben comprobar una serie de elementos que pueden afectar a la seguridad de la operación.

- Para realizar esta comprobación, el operador o el piloto a distancia debe verificar, empleando el concepto **MEUH**, los siguientes componentes:
  - **Meteorología (M)**.
  - **Entorno (E)**.
  - **UAS (U)**.
  - **Limitaciones humanas (H)**.
