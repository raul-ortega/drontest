# Diapositiva 16 — Concepto Normativo · Definiciones importantes

### Sistema de geoconsciencia
- Función que, sobre la base de los datos facilitados por los Estados miembros, **detecta una posible violación de las limitaciones del espacio aéreo** y **alerta a los pilotos a distancia** para que puedan tomar medidas inmediatas y eficaces para evitarla.

### Sistema de identificación a distancia directa (DRI)
- Sistema que garantiza la **emisión local de información** sobre las aeronaves no tripuladas en funcionamiento, incluido el **marcado** de estas aeronaves, de modo que la información pueda obtenerse **sin acceder físicamente** a las aeronaves.

### Zona geográfica de UAS
- Parte del espacio aéreo establecida por la autoridad competente que **facilita, restringe o excluye** operaciones de UAS para gestionar riesgos para la seguridad, la protección, la privacidad, la protección de datos personales o el medio ambiente.
- Se distingue entre zonas geográficas UAS **generales** y **particulares**.

### Modo sígueme (*follow-me*)
- Modo de funcionamiento en el que la aeronave no tripulada **sigue constantemente al piloto a distancia** dentro de un radio predeterminado.
