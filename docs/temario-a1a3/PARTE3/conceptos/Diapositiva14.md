# Diapositiva 14 — Procedimientos operacionales durante el vuelo: Procedimiento de contingencia o de emergencia (medidas)

*(Lección 3 - Procedimientos operacionales — pageid 134)*

## Contenido

- Las medidas que el piloto a distancia debe tomar para cada situación de vuelo anómala serán diferentes según el tipo de aeronave con la que opere; por lo tanto, deberá verificar el procedimiento de actuación de acuerdo con las indicaciones del fabricante del UAS dadas en sus instrucciones.
