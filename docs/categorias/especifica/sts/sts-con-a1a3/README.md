# STS — Con certificado A1/A3

Examen teórico para pilotos que ya disponen del certificado de conocimientos teóricos A1/A3.

## Examen

| Parámetro | Valor |
|-----------|-------|
| Preguntas | 40 tipo test |
| Duración | 40 minutos |
| Nota mínima | 75% |
| Materias | 8 materias (según Syllabus) |
| Intentos | 2 por matriculación |
| Formato | Online con televigilancia (webcam, micrófono, pantalla) |

## Procedimiento

1. Inscribirse en la Oficina Virtual de AESA
2. Plazo de 30 días desde la notificación de acceso
3. Examen con televigilancia
4. Superar con ≥75% de respuestas correctas

## Formación práctica

Tras superar el teórico, se requiere formación práctica específica para cada escenario (STS-01 o STS-02) impartida por entidades reconocidas.

## Banco de preguntas

Por definir.待 contenido basado en el Syllabus del Reglamento de Ejecución (UE) 2019/947.
