# Diapositiva 28 — Concepto Normativo · Categoría «abierta» — Subcategoría A1

## UAS con etiqueta de clase C1 — requisitos

- Altura máxima de vuelo **limitada a 120 m**.
- **MTOM < 900 g**.
- Velocidad máxima **< 19 m/s**.
- Controlable y manejable de forma segura; diseñado para no dañar a personas.
- **Energía de impacto < 80 J**.
- Dispone de **método para finalizar el vuelo de forma segura** o recuperar el enlace en caso de pérdida.
- **Identificación a distancia (DRI)**.
- **Eléctrico**.
- **Sistema de Geoconsciencia**.
- **Número de serie físico y único**.
- Equipado con **luces de controlabilidad y visibles de noche**.
- Comercializado con las instrucciones del fabricante.
