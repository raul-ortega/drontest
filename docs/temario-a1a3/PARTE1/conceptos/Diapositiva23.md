# Diapositiva 23 — Concepto Normativo · Categoría «abierta»

**6. Mercancías peligrosas:**
- **Está prohibido el transporte de mercancías peligrosas** con el UAS.
- Está prohibido **dejar caer o proyectar ningún material u objeto**.

## Clasificación de mercancías peligrosas (clases ADR en la diapositiva)

| Clase | Tipo |
|---|---|
| 1 | Explosivos |
| 2 | Gases |
| 3 | Líquidos inflamables |
| 4 | Sólidos inflamables |
| 5 | Sustancias oxidantes |
| 6 | Sustancias tóxicas e infecciosas |
| 7 | Material radiactivo |
| 8 | Sustancias corrosivas |
| 9 | (Residual / diversas) |
