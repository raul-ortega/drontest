# Temario oficial UAS-Certificación A1/A3 (texto)

Extracto en Markdown del temario oficial del curso **UAS-Certificación A1/A3** de
AESA. Es la fuente documental del banco de preguntas de `prisma/data/`.

| Carpeta | Parte | Diapositivas | Documento |
|---|---|---|---|
| `PARTE1/` | Concepto normativo | 55 | FOR-UAS-P01-DT01, Ed. 09 (julio 2024) |
| `PARTE2/` | Conocimientos generales | 85 | Lección 2 del curso |
| `PARTE3/` | Procedimientos operacionales | 21 | Versión 4 (noviembre 2022) |

Cada carpeta contiene:

- `conceptos/DiapositivaN.md` — texto de cada diapositiva.
- `md_index.md` — índice diapositiva → archivo → título.
- `README-aesa.md` — información general del curso publicada por AESA.

## Procedencia

El material completo (texto, imágenes y volcados de página) se descargó de la
plataforma de formación de AESA:

- <https://sede.seguridadaerea.gob.es/formacion/>
- <https://sede.seguridadaerea.gob.es/formacion/course/view.php?id=6>

En este repositorio se versiona **solo el texto** (unos 700 KB). Las imágenes de
las diapositivas no se incluyen por tamaño. En el equipo de desarrollo, el
material completo está enlazado en `docs/Certificacion-A1A3` (ignorado por Git).

## Uso

Las preguntas de `prisma/data/preguntas-parte{1,2,3}.json` citan la parte y la
diapositiva de origen en el campo `referencia`. Para revisar o ampliar una
pregunta, abre el `.md` correspondiente de `conceptos/`.

## Aviso

Este material pertenece a AESA y se usa aquí como documentación pública de
formación. Las preguntas del banco son elaboradas a partir de él y **no** son
preguntas oficiales del examen.
