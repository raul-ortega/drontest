# Diapositiva 9 — Procedimientos operacionales previos al vuelo: Limitaciones humanas

*(Lección 3 - Procedimientos operacionales — pageid 137)*

## Contenido

- Antes de iniciar una operación, el piloto a distancia debe verificar que se encuentra en condiciones óptimas para llevar a cabo la operación. Para ello, el piloto a distancia deberá usar la metodología **IM SAFE**, tal y como se ha visto en el apartado de «Limitaciones de factores humanos» de este curso de formación.

- Componentes de la metodología **IM SAFE**:
  - **Enfermedad** (*illness*).
  - **Medicación**.
  - **Estrés** (*stress*).
  - **Alcohol**.
  - **Fatiga**.
  - **Emociones**.

- Además, como ya se ha visto anteriormente, el piloto debe tener en cuenta las limitaciones propias de la percepción humana para, de esta forma, realizar un vuelo seguro.
