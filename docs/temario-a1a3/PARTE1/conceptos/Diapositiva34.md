# Diapositiva 34 — Concepto Normativo · Categoría «abierta» — Subcategoría A3

## UAS con etiqueta de clase C4 — requisitos

- **MTOM < 25 kg**.
- Controlable y manejable de forma segura.
- **NO dispone de modo automático de vuelo**, excepto de **asistencia a la estabilización** (en caso de pérdida de conexión).
- Comercializado con las instrucciones del fabricante.
